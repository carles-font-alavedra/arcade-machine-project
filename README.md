# Tabletop Arcade Machine

A two-player tabletop arcade cabinet built around a Raspberry Pi, with more than 14,000 games. I designed, built and coded it over about a year, and sold it to a fellow gaming enthusiast.

## Specs

| | |
|---|---|
| Brain | Raspberry Pi, with a power switch |
| Games | 14,000+ |
| Players | 2, each with 1 joystick and 6 buttons |
| Screen | 17-inch computer monitor |
| Sound | Two front speakers |
| Lighting | LED strip |
| Cabinet | Wood, with Donkey Kong-themed vinyl artwork |
| Maintenance | Rear door for access to the electronics and ventilation |

## What I did

The whole build, end to end:

- **Design:** cabinet shape, control panel layout and artwork.
- **Build:** cutting and assembling the wooden cabinet, mounting the screen, speakers, controls and LEDs.
- **Electronics and software:** wiring the controls, screen, audio and power to the Raspberry Pi, and setting up the system and game library.

Accessibility and maintenance were priorities from the start, which is why the electronics sit behind a rear door instead of being sealed in.
